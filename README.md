### What I learned
This challenge was very interesting as it introduced me to the concept of dynamic view switching. In the past, I thought such functionality required multiple HTML pages, but through this challenge I have learnt that modern web development handles it all on a single page as this approach results in faster loading (no page reload), a smoother user experience, and easier state management (keeping the selected rating in memory).



### Continued development

I hope to continue working on my css skills. In this challenge, I still had to make use of media queries, which I felt should have been unncessary. I will continue to improve on my HTML structuring so as to enable better styling. I also would continue working on my JavaScript so as to write more functional codes.
